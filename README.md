# 단톡방 사전

## 폴더 구성
- `server.js` : 백엔드 서버 (로그인/회원가입/프로필 처리)
- `package.json` : 필요한 패키지 목록
- `public/` : 사이트 화면 (index.html / style.css / script.js / dictionary.json)
- `users.json` : 가입한 멤버들의 계정 정보 (서버 처음 실행하면 자동 생성됨, ⚠ 절대 공유 금지)
- `uploads/` : 멤버들이 올린 프로필 사진이 저장되는 폴더 (서버 처음 실행하면 자동 생성됨)

## 처음 실행할 때 (딱 한 번만)
VS Code에서 이 폴더를 열고, 터미널(상단 메뉴 `터미널 > 새 터미널`)에서:
```
npm install
```
필요한 패키지들을 설치해요. 조금 시간 걸릴 수 있어요.

## 서버 실행하기
```
npm start
```
터미널에 `http://localhost:3000` 이라고 뜨면, 그 주소를 브라우저에 붙여넣어서 접속하면 돼요.

**주의**: Live Server 확장 프로그램은 이제 안 써요! 로그인 기능은 서버(`npm start`)가 켜져 있어야만 작동해요.

## 친구들도 같은 와이파이에서 보게 하려면
1. 터미널에서 `ipconfig`(윈도우) / `ifconfig`(맥)로 내 IP 확인 (예: 192.168.0.15)
2. `npm start`로 서버 켜두기
3. 친구들 폰 브라우저에 `http://내IP주소:3000` 입력 (예: `http://192.168.0.15:3000`)
4. 각자 회원가입 → 로그인 → 자기 프로필 카드에서 ✎ 버튼으로 닉네임/이름/색깔/사진 수정 가능 ("사진 선택"으로 프로필 사진 업로드, 5MB 이하 이미지만 가능. "사진 삭제"를 누르면 다시 색상 아바타로 돌아감)
5. 내 컴퓨터를 끄면 서버도 꺼져서 다들 접속이 안 돼요. 다시 켤 땐 `npm start`만 다시 하면 됨 (가입 데이터는 `users.json`에 저장되어 있어서 안 사라져요)

## 단어 추가하는 법
`public/dictionary.json`을 열어서 아래 형식으로 한 줄씩 추가하면 됨:
```json
{ "term": "은어", "meaning": "뜻", "note": "선택사항 - 부가 설명" }
```

## 로딩 화면 / 배경음악
- 사이트에 들어가면 컨트롤러 아이콘이 통통 튀는 로딩 화면이 잠깐 나온 뒤 자동으로 사라져요.
- 배경음악을 넣으려면, 원하는 mp3 파일 이름을 **`bgm.mp3`로 바꿔서 `public` 폴더 안에** 넣어주세요. (즉 `public/bgm.mp3` 경로가 되어야 해요)
- 오른쪽 위 🔇 버튼을 누르면 그 mp3가 재생돼요 (다시 누르면 정지). 파일을 안 넣었거나 이름이 다르면 버튼을 눌러도 소리가 안 나요 — 그럴 땐 `public/bgm.mp3` 파일이 있는지, 이름이 정확한지 확인해주세요.
- 브라우저는 사용자가 클릭하기 전엔 소리 자동재생을 막아놔서, 첫 방문 땐 버튼을 한 번 눌러줘야 소리가 나요. 이후 다시 접속했을 때 저번에 음악을 켜뒀었다면, 화면 아무 곳이나 한 번 클릭/터치하면 자동으로 다시 재생돼요.
- 다른 파일 형식(wav, ogg 등)을 쓰고 싶으면 `public/index.html`에서 `<audio id="bgmAudio" src="bgm.mp3" ...>` 부분의 `bgm.mp3`를 원하는 파일명으로 바꿔주면 돼요.

## 주의할 점
- `users.json`에는 (해시된) 비밀번호와 실명이 들어있어요. 이 파일은 절대 GitHub 같은 곳에 올리면 안 돼요 (`.gitignore`에 이미 추가되어 있어요).
- 이 로그인 시스템은 친구들끼리 편하게 쓰라고 만든 간단한 버전이에요. 은행 앱처럼 강력한 보안은 아니니, 중요한 개인정보(주민번호, 계좌번호 등)는 절대 올리지 마세요.
